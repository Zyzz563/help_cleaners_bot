# 🤖 Help Cleaners | Telegram Bot

Бот для автоматизации работы клининговых бригад в Telegram.

## 📋 Возможности

- ✅ Регистрация клинеров в группе
- ✅ Управление сменами (дневные/ночные)
- ✅ Автоматический табель учета рабочего времени
- ✅ Детекция дубликатов фотографий
- ✅ Защита от несанкционированного использования
- ✅ Система напоминаний о сменах

## 🔧 Команды бота

### Для клинеров:
- `/register` - Регистрация в группе
- `/shift` - Записаться на смену
- `/add_shift` - Добавить смену в табель
- `/remove_shift` - Удалить смену из табеля
- `/tabel` - Посмотреть свой табель
- `/today` - Кто сегодня работает
- `/myshifts` - Мои смены
- `/cleaners` - Список всех клинеров
- `/duplicates` - Список дубликатов фото
- `/help` - Помощь

### Для владельца:
- `/addchat` - Добавить группу в разрешенные
- `/removechat` - Убрать группу из разрешенных
- `/listchats` - Список разрешенных групп
- `/remove` - Удалить клинера

## 🛠️ Технологии

- **Python 3.11+**
- **aiogram 3.4** - Telegram Bot Framework
- **SQLAlchemy 2.0** - ORM для работы с БД
- **SQLite** - База данных
- **APScheduler** - Планировщик задач

## 🔐 Безопасность

- Бот работает только в разрешенных группах
- Только владелец может добавлять новые группы
- Автоматическая детекция дубликатов фотографий
- Защита от спама и злоупотреблений

## 📊 База данных

Используется SQLite с автоматической миграцией схемы при запуске.

**Таблицы:**
- `groups` - Группы
- `members` - Клинеры
- `shifts` - Смены
- `timesheets` - Табель
- `photos` - Фотографии
- `photo_duplicates` - Дубликаты фото
- `allowed_chats` - Разрешенные чаты
