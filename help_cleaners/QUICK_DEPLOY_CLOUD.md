# 🚀 БЫСТРЫЙ ДЕПЛОЙ НА RAILWAY

## Шаг 1: Регистрация
1. Иди на https://railway.app
2. Нажми "Login" → "GitHub"
3. Авторизуйся через GitHub

## Шаг 2: Создание проекта
1. Нажми "New Project"
2. Выбери "Deploy from GitHub repo"
3. Найди репозиторий `Zyzz563/help_cleaners_bot`
4. Нажми "Deploy"

## Шаг 3: Настройка переменных
1. В проекте нажми на сервис
2. Перейди во вкладку "Variables"
3. Добавь переменные:
   - `BOT_TOKEN` = твой токен бота
   - `OWNER_ID` = твой Telegram ID

## Шаг 4: Запуск
1. Railway автоматически запустит бота
2. Проверь логи во вкладке "Deployments"
3. Бот будет работать 24/7!

## 🎯 Альтернатива: RENDER
1. Иди на https://render.com
2. "New" → "Web Service"
3. Подключи GitHub репозиторий
4. Настрой переменные окружения
5. Deploy!
